# Ibra Digital Engineering

Website resmi dan landing page standalone untuk **Ibra Digital Engineering** (Layanan Pembuatan Website Premium, Digital Systems & High-Security Architecture).

## 🚀 Cara Menjalankan Project

1. Buka terminal di folder project ini:
   ```bash
   cd /Users/husnitausman/Documents/ibra-digital
   ```

2. Install dependensi:
   ```bash
   npm install
   ```

3. Jalankan server lokal:
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan di `http://localhost:3001`.

## 📁 Struktur Folder
- `src/app/page.tsx`: Halaman utama Ibra Digital Engineering
- `src/app/DigitalAgencyClient.tsx`: Komponen tampilan utama & animasi GSAP
- `src/app/privacy/`: Halaman Kebijakan Privasi
- `src/app/terms/`: Halaman Syarat & Ketentuan
- `src/components/`: Sub-komponen UI (Hero, Portfolio, Pricing, Features, Order Form)
- `public/assets/`: Logo & aset visual resmi Ibra Digital Engineering
